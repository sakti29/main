# BookVerse - Katalog Buku Digital

## Deskripsi Project
BookVerse adalah sebuah website statis responsif yang berfungsi sebagai katalog ulasan dan sinopsis buku pilihan. Website ini dirancang untuk memudahkan pengguna mencari rekomendasi bacaan literasi yang menarik melalui antarmuka yang bersih dan interaktif.

## Fitur & Struktur Section
1.  **Home / Hero Section:** Judul platform, deskripsi singkat, dan call-to-action (CTA) langsung menuju katalog.
2.  **About / Profile:** Latar belakang platform beserta visi dan misi pembuatan web.
3.  **Main Content (Catalog Buku):** Grid responsif berisi kartu ulasan buku lengkap dengan fitur pencarian real-time berbasis JavaScript.
4.  **Contact & Footer:** Formulir kontak interaktif dan hak cipta platform kelompok.

## Teknologi yang Digunakan
*   HTML5 (Struktur halaman)
*   CSS3 (Styling & layouting Grid/Flexbox)
*   JavaScript Dasar (Logika manipulasi DOM untuk filter pencarian)

## Cara Menjalankan Secara Lokal
1.  Clone repository ini ke perangkat komputer lokal Anda:
    ```bash
    git clone https://github.com
    ```
2.  Buka folder project hasil clone tersebut.
3.  Klik dua kali pada file `index.html` untuk menjalankannya langsung di web browser pilihan Anda.
